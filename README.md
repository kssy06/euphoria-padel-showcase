# Euphoria Padel

**Website and booking system for a real padel club in Ezzahra, Tunisia.** Players book a court in about 30 seconds, with no account needed.

**What it does**
- 90-minute slots, open 24/7: players just enter a name and phone number
- The club confirms each booking from its admin panel
- Pages for tournaments, events, the gallery and announcements, in French and English

**Built with** Next.js · React · TypeScript · PostgreSQL
